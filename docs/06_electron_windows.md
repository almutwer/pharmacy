# 06 - تشغيل نسخة Electron على Windows

هذه النسخة لا تحتاج Python. تحتاج فقط:

- Node.js LTS من https://nodejs.org
- npm يأتي مع Node.js

## 1. فك ضغط المشروع

ضع المشروع في مسار بسيط، مثلاً:

```text
C:\pharmacy
```

ثم افتح CMD أو PowerShell داخل المجلد:

```cmd
cd /d C:\pharmacy
```

## 2. تثبيت الحزم

```cmd
npm install
```

إذا ظهرت مشكلة شهادة SSL أثناء تحميل Electron، جرب مؤقتاً:

```cmd
set NODE_TLS_REJECT_UNAUTHORIZED=0
npm install
```

ثم أغلق النافذة وافتحها من جديد بعد اكتمال التثبيت.

## 3. تشغيل التطبيق أثناء التطوير

```cmd
npm run dev
```

سيفتح تطبيق Electron بواجهة عربية RTL.

## 4. بناء ملف EXE لويندوز

```cmd
npm run dist
```

بعد الانتهاء ستجد الملفات داخل:

```text
release\
```

ومنها ملف مثبت أو Portable باسم قريب من:

```text
PharmacyDesktop-1.0.0-x64.exe
```

## 5. مسار قاعدة البيانات

يتم حفظ قاعدة البيانات المحلية تلقائياً في مجلد بيانات التطبيق الخاص بويندوز، ويمكن رؤية المسار من:

```text
الإعدادات → معلومات النظام
```

يمكن تغيير المسار بمتغير بيئة اختياري:

```cmd
set PHARMACY_DB_PATH=D:\PharmacyData\pharmacy.db
npm run dev
```

## 6. أول تشغيل

عند فتح البرنامج لأول مرة:

1. افتح `⚙️ الإعدادات`.
2. افتح تبويب `استيراد دليل الأدوية`.
3. اختر ملف Excel / CSV / JSON.
4. طابق الأعمدة.
5. اضغط `تأكيد الاستيراد`.

> تذكير: استيراد دليل الأدوية لا يضيف أي كمية للمخزون.

## 7. تحميل بيانات تجريبية للاختبار

من داخل التطبيق:

```text
الإعدادات → معلومات النظام → تحميل بيانات تجريبية للاختبار
```

لا تستخدم هذا الخيار على قاعدة بيانات الصيدلية الحقيقية.
