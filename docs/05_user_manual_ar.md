# 05 - دليل المستخدم العربي المبسط

## 1. فتح البرنامج

بعد تشغيل البرنامج تظهر الشاشة الرئيسية وبها 4 أزرار كبيرة:

- 💊 نقطة البيع
- 📦 المخزون
- 📊 التقارير
- ⚙️ الإعدادات

إذا ظهر تحذير أحمر أعلى الشاشة، فهذا يعني أن النسخ الاحتياطي لم يتم منذ عدة أيام.

## 2. استيراد دليل الأدوية لأول مرة

> مهم: استيراد دليل الأدوية لا يضيف أي كمية للمخزون.

الخطوات:

1. افتح `⚙️ الإعدادات`.
2. اختر تبويب `استيراد دليل الأدوية`.
3. اضغط `استيراد دليل الأدوية - اختيار ملف`.
4. اختر ملف Excel أو CSV أو JSON.
5. سيعرض البرنامج أول 20 صف للمراجعة.
6. طابق الأعمدة:
   - الباركود -> عمود الباركود في الملف
   - الاسم التجاري -> عمود اسم الدواء
   - المادة الفعالة -> اختياري
   - السعر الرسمي -> اختياري
7. اضغط `تأكيد الاستيراد`.
8. ستظهر رسالة بعدد الأدوية التي تم استيرادها.

## 3. إضافة مخزون جديد

استخدم هذه الشاشة عند وصول أدوية فعلية للصيدلية.

1. افتح `📦 المخزون`.
2. امسح باركود الدواء أو اكتبه ثم اضغط Enter.
3. إذا كان الدواء موجوداً في دليل الأدوية، ستظهر بياناته.
4. أدخل:
   - الكمية
   - سعر الشراء
   - سعر البيع
   - تاريخ الانتهاء بصيغة `YYYY-MM-DD`
   - رقم الدفعة
   - المورد
   - مكان التخزين
5. اضغط `حفظ المخزون والعودة للباركود`.

### ملاحظات مهمة

- لا يمكن إضافة دواء منتهي الصلاحية.
- لا يمكن إدخال كمية سالبة.
- إذا كان سعر البيع أقل من سعر الشراء، سيظهر تحذير ويسجل النظام ذلك في سجل التدقيق.

## 4. البيع من نقطة البيع

1. افتح `💊 نقطة البيع`.
2. امسح باركود الدواء أو ابحث باسمه.
3. يضاف الدواء للفاتورة إذا كان متاحاً في المخزون.
4. لإضافة نفس الدواء مرة أخرى، امسح الباركود مرة ثانية.
5. أدخل الخصم إن وجد.
6. اختر طريقة الدفع:
   - 💵 كاش
   - 💳 فيزا
   - 🏥 تأمين
7. يتم حفظ الفاتورة وخصم الكمية وطباعة/حفظ الإيصال.

### الحالات التي يمنع فيها البيع

- الدواء غير موجود بالمخزون.
- الكمية نفدت.
- الدواء منتهي الصلاحية.
- الكمية المطلوبة أكبر من المتاح.

### التحذيرات

إذا كان الدواء ينتهي خلال 30 يوم، يعرض البرنامج تحذيراً لكنه يسمح بالبيع.

## 5. الاختصارات

| الاختصار | الوظيفة |
|---|---|
| F2 | البحث في نقطة البيع |
| F5 | فاتورة جديدة |
| F8 | الخصم |
| F12 | إتمام البيع والطباعة |
| ESC | إلغاء الفاتورة الحالية |
| Delete | حذف صنف محدد |

## 6. التقارير

افتح `📊 التقارير` ثم اختر التقرير المطلوب:

1. تقرير المبيعات اليومي
2. تقرير المخزون
3. تقرير الصلاحية 30/60/90 يوم
4. تقرير الأرباح
5. تقرير الموردين
6. تقرير الأصناف الراكدة

## 7. النسخ الاحتياطي

1. افتح `⚙️ الإعدادات`.
2. اختر تبويب `النسخ الاحتياطي`.
3. اضغط `إنشاء نسخة احتياطية الآن`.
4. لحفظ نسخة على USB، اضغط `نسخ إلى USB` واختر الفلاش.

## 8. وصف لقطات الشاشة المطلوبة لاحقاً

عند تجهيز نسخة نهائية للموظفين، يمكن إضافة صور حقيقية لهذه المواضع:

- صورة الشاشة الرئيسية مع الأزرار الأربعة.
- صورة استيراد دليل الأدوية ومطابقة الأعمدة.
- صورة إضافة مخزون بعد مسح باركود.
- صورة فاتورة في نقطة البيع.
- صورة شاشة التقارير.
- صورة النسخ الاحتياطي.
