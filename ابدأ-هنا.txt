   💊  نظام إدارة الصيدليات الشامل — دليل التشغيل السريع
════════════════════════════════════════════════════════════

المتطلبات:
  • Node.js إصدار 22 أو أحدث   (تحقق بالأمر:  node -v)

────────────────────────────────────────────────────────────
① فكّ ضغط الملف ثم افتح موجه الأوامر داخل مجلد المشروع
────────────────────────────────────────────────────────────

② تثبيت الحزم  (مرة واحدة فقط، يحتاج إنترنت):

      npm install

③ تجهيز قاعدة البيانات مع بيانات تجريبية واقعية:

      npm run reset

   (قاعدة بيانات جاهزة مرفقة أصلاً في server/data/pharmacy.db
    — استخدم هذا الأمر فقط إذا أردت إعادة توليد البيانات من جديد)

④ تشغيل النظام:

      npm run dev

   ثم افتح المتصفح على:   http://localhost:5173

────────────────────────────────────────────────────────────
🔑 حسابات الدخول التجريبية
────────────────────────────────────────────────────────────
   admin      / admin123     → مدير النظام (كل الصلاحيات)
   manager    / manager123   → مدير الصيدلية (تقارير وأرباح)
   pharmacist / pharma123    → صيدلي (مخزون ومشتريات)
   cashier    / cash123      → كاشير (بيع ومرتجعات)

   ⚠️ غيّر كلمات المرور من: الإعدادات ← المستخدمون
      قبل أي استخدام حقيقي.

────────────────────────────────────────────────────────────
🚀 وضع الإنتاج (خادم واحد)
────────────────────────────────────────────────────────────
      npm run build
      npm start
   ثم:   http://localhost:4000

────────────────────────────────────────────────────────────
📦 محتويات النظام
────────────────────────────────────────────────────────────
   • دليل الأدوية    : مرجع دوائي لا يظهر في المخزون، يُستخدم
                       لإدخال الأدوية للمخزون وفواتير الشراء
   • المخزون        : دفعات + تواريخ صلاحية + صرف FEFO + تسويات
   • نقطة البيع     : بيع سريع بالباركود + مرتجعات + طباعة فاتورة
   • المشتريات      : فواتير توريد تُرحّل للمخزون + مستحقات الموردين
   • المصروفات      : تصنيفات ورسوم بيانية
   • الأرباح        : قائمة دخل كاملة وصافي الربح وهامش الربحية
   • التقارير       : مبيعات، مشتريات، تقييم مخزون، أداء الموظفين
   • الصلاحيات      : 4 أدوار + سجل نشاط + نسخ احتياطي

   📄 التفاصيل الكاملة في ملف README.md
